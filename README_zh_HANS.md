# Blender Source Tools — SMD/VTA 工作流增强版

**简体中文** · [English](README.md)

基于 **Blender Source Tools** 改造，重点改善起源引擎模型制作中的网格导出性能、形态键导出范围与导出项配置体验。

**目标 Blender 版本：4.0.2。** 随附源码的原始版本信息为 **Blender Source Tools 3.2.6**。本增强版由 [Kokkorylien](https://github.com/Kokkorylien) 独立维护，属于非官方衍生版本。

## 原插件功能概览

Blender Source Tools 提供 SMD/VTA、DMX 的导入导出、骨架动画与表情相关工具，以及 QC 相关功能，服务于 Valve 引擎的模型制作流程。本增强版保留这些基础，主要改进网格 SMD 与形态键 VTA 导出；QC 生成、编译流程和原有顶点动画工具沿用上游行为。

## 本增强版的主要改动

### 每个导出项独立选择 SMD/VTA 模式

集合或网格导出项可以分别保存自己的导出模式：

| 模式 | 输出与处理方式 |
| --- | --- |
| SMD + VTA | 导出网格 SMD；存在可导出的形态键时，同时导出形态键 VTA。 |
| 仅 SMD | 导出基础网格，**跳过形态键烘焙和 VTA 生成**。 |
| 仅 VTA | 导出形态键 VTA，保留现有网格 SMD。 |

**“仅 SMD”会省去逐个形态键烘焙的耗时。** 原工程中的形态键全部保留，基础网格使用第一个基型形态键求值。即使网格拥有成百上千个形态键，也可以快速进行日常网格导出。网格本身、修改器等其他导出处理仍会产生相应耗时。

使用“仅 VTA”时，已有 SMD 必须与本次 VTA 烘焙使用的几何和顶点顺序对应。影响这种对应关系的网格改动完成后，应重新导出 SMD。

### 指定首尾形态键，保留暂时不用的形态键

每个导出项可以独立设置 **VTA 起始形态键**和 **VTA 结束形态键**，范围包含首尾两端。

例如，网格的形态键从上到下依次为：

~~~text
basis、blink、angry、smile_1、smile_2、shape1、shape2、shapeblank、shape3
~~~

将首尾设为 **shape1 → shapeblank**，得到：

| VTA 帧 | 对应形态键 |
| --- | --- |
| 0 | basis |
| 1 | shape1 |
| 2 | shape2 |
| 3 | shapeblank |

第 0 帧始终使用物体最上面的第一个形态键，通常为 Basis；选中范围内的非基型形态键从第 1 帧开始连续编号。其他形态键仍留在 Blender 工程中，本次导出不烘焙这些范围外的形态键。

起始端或结束端留空时，分别使用可导出非基型形态键的开头或结尾。不存在的端点、起止顺序颠倒等问题会在导出前提示。

一个集合内的多个网格可以拥有不同的形态键列表。导出器按照遍历网格的顺序合并名称，同名形态键只保留第一次出现的位置；首尾设置作用于这个合并列表。某个网格缺少对应形态键时，该帧保持其基础几何；第 0 帧使用各网格自己的第一个形态键。配置集合时，可通过界面中的范围与帧数摘要确认结果。

**QC 中的表情帧编号需要与导出的 VTA 一致，由用户自行调整。**

### 大型 VTA 导出前确认

选择“SMD + VTA”或“仅 VTA”时，会在开始耗时烘焙前检查导出规模。确认框显示形态键帧数与估算体积，方便在误操作时及时取消。

场景级确认选项的默认值为：

| 选项 | 何时弹出确认 |
| --- | --- |
| 形态键帧数：64 | 任一导出项需要写入超过 64 帧非基型形态键。 |
| 估算体积：128 MB | 本次操作的 VTA 估算总体积超过 128 MB；这里 1 MB 按 1,024 × 1,024 字节计算。 |

这两个数值表示**“导出多大时先询问”**，确认后仍可继续导出。某项设为 0，可单独关闭对应检查。体积属于偏保守的估算，实际文件可能更小。后台导出会记录警告并继续执行，不弹出交互式确认框。

### 可选“忽略形态键法线”

每个导出项可以独立开启**忽略形态键法线**：

- 形态帧沿用基础网格法线。
- 这些帧只写入位置发生变化的顶点。
- 忽略仅法线发生变化的情况，并跳过逐形态键法线计算。

VTA 仍然保留格式要求的法线列。开启后，导出的表情变形不会同步更新光照法线；需要保留形态法线变化时，应关闭此选项。

### 更直接、稳定的导出项定位与配置

**所选导出项**面板会跟随场景中选中的物体或集合，包括按 H 隐藏或禁用视口显示的网格物体。

- 选择集合时，定位这个集合的导出项。
- 选择网格时，按实际集合归属定位导出项；其他集合与网格同名不会造成误匹配。
- 在**起源引擎导出项**列表中点击一行，也能切换配置目标，同时保留场景中的物体选择、活动物体和活动集合。
- 重新选择场景物体或集合后，恢复跟随场景选择。
- 导出列表刷新时，按物体或集合身份保留定位。

可通过“所选导出项”面板和导出菜单快速调整当前目标的 SMD/VTA 模式、忽略法线设置。列表中也会在适用项的形态键数量旁显示导出模式与忽略法线标记。

### 批量应用导出配置

**起源引擎导出项 → 批量导出设置**支持将 SMD/VTA 模式和忽略形态键法线设置应用到所选导出目标或全部适用导出项。“所选”可以来自场景选择，也可以来自独立点选的导出列表行。

骨架动画导出项不参与这些网格/VTA 设置的批量应用。首尾形态键仍按导出项分别设置。

### 普通集合内也能直接选择骨架动画导出项

骨架放在普通集合或嵌套集合中时，仍可直接选择它对应的动作或 NLA 动画导出项，无需为了导出动画而移动到场景根集合。

选择骨架可定位其动画导出项；选择集合时，则继续定位该集合的导出项。

### 简体中文界面与悬停提示

为插件界面字符串、设置、鼠标悬停说明及提示消息补充简体中文翻译，并结合 Valve 模型制作语境整理术语，例如将 Source engine 译为“起源引擎”。

## 安装与快速使用

1. 使用 Blender 4.0.2；若已安装原版 Blender Source Tools，请先禁用。两者使用同一个模块名 `io_scene_valvesource`。
2. 打开**编辑 → 偏好设置 → 插件 → 安装**，选择本增强版的安装 ZIP，启用 Blender Source Tools。
3. 使用包含 `io_scene_valvesource/` 文件夹的发行安装包。GitHub 自动生成的源码 ZIP 是仓库快照，目录结构可能不同。
4. 在**场景属性 → 起源引擎导出**中设置导出路径，将格式选为 **SMD**。
5. 选择集合、网格，或点击“起源引擎导出项”列表行。在“所选导出项”中调整模式和法线；首尾形态键在导出项下方的 **SMD / VTA** 面板中设置。
6. 通过场景属性中的导出按钮，或**文件 → 导出 → 起源引擎**执行导出。

使用中文界面时，在 Blender 的界面语言中选择简体中文，并启用界面及工具提示翻译。
